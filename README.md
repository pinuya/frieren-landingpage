## ✨ Features

### ✅ Implemented

- **Hero Section** - Initial banner with impressive visual effects
- **About** - Detailed description of the anime and its story
- **Characters** - Interactive gallery of main characters

### 🛠️ Technologies Used

- **Remix v2** - Full-stack React framework
- **TypeScript** - Static typing for greater reliability
- **Fancy Elements** - Elegant and modern UI components
- **Framer Motion** - Fluid and interactive animations
- **Tailwind CSS** - Utility-first responsive styling
- **Vite** - Fast and efficient build tool

### 🚀 How to Run

**Prerequisites**

- Node.js 18+
- bun

**Installation**

```bash
# Clone the repository
git clone git@github.com:pinuya/frieren-landingpage.git

# Install dependencies
bun install

# Start the development server
bun dev
```

The site will be available at http://localhost:3000
